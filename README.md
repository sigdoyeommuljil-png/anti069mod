# anti069 공포 모드 (Minecraft 26.2 / Fabric)

## 등장 NPC

**anti069** — 공포 컨셉. 4단계로 진행됩니다.
1. 평범한 플레이어인 척 배회
2. 시비(우클릭)나 공격을 받으면 Groq AI로 불편해하는 대사
3. 시비 3회 또는 고의 공격 2회 이상 → 30% 확률로 "나간 척"
   (`anti069이(가) 게임에서 나갔습니다` 노란 메시지 + 사라짐)
4. 60초 뒤 괴물로 각성 → 포효 + 무한 추적 + 맞아도 안 죽음 + 그르렁

각성 시: 머리 사라지고 오른팔/왼다리가 길게 뒤틀리며, 피칠갑 스킨 +
크기 1.8배 + 걷기 애니메이션 없이 뻣뻣하게 다가옵니다.

**069_36** — 친근한 중립 대화 NPC. 근처(12칸)에서 플레이어가 채팅을 치면
Groq AI로 답합니다. 먼저 공격하지 않습니다.

## ⚠️ 설치 전 필수 — Groq 키 파일 2개

두 NPC의 대화는 Groq AI를 씁니다. **키는 모드에 안 들어있고**, 게임 폴더에서 읽어옵니다.
게임 실행하는 `.minecraft` 폴더 안에 아래 두 파일을 만들고 각각 본인 키를 붙여넣으세요:

- `groq_key_hostile.txt`  → anti069 용 키
- `groq_key_neutral.txt`  → 069_36 용 키

(파일이 없거나 비어 있으면 AI 대사 대신 기본 대사가 나옵니다. 크래시는 안 남.)

Groq 모델은 기본 `llama-3.3-70b-versatile` 입니다. 바꾸려면
`src/main/java/com/anti069/mod/ai/GroqClient.java` 의 MODEL 한 줄만 고치면 됩니다.

## 소환 (치트 켠 상태)

```
/summon anti069mod:anti069 ~ ~ ~
/summon anti069mod:069_36 ~ ~ ~
```

## 같이 하려면

이건 참여자 **전원**이 이 모드 + Fabric API 를 설치해야 다 같이 보입니다.
한 명만 깔면 그 사람 화면에만 나옵니다.

## 아직 안 들어간 것 (다음 단계)

- **Tab 목록 / 로케이터바에 가짜 플레이어로 표시**: 26.2에서 이 부분 API가
  가장 까다롭고 검증이 안 돼서 이번 빌드에는 넣지 않았습니다. 기본 동작이
  잘 굴러가는 걸 확인한 뒤 별도로 붙이는 걸 권합니다.
- 진짜 커스텀 3D 괴물 모델(GeckoLib): 지금은 사람 모델을 변형하는 방식.

## 버전 주의

26.2는 2026년 6월에 나온 최신이라, `gradle.properties`의 정확한 빌드번호
(yarn/fabric-api)와 클라이언트 렌더러/모델 관련 클래스 이름은 실제 26.2
매핑과 다를 수 있습니다. 빌드 오류가 나면 로그를 확인해 이름을 맞춰주세요.
